THAT’S MY LINGO! – Play & Grow Demo (Static Prototype)
=========================================================

This folder contains a simple, static HTML/JS prototype you can open in any browser.
It simulates:
 - watching ads (demo countdown) to earn virtual Lingo Coins
 - daily/weekly goals
 - a phrase challenge mini-game
 - referral system (referrer & referee rewards)
 - a community funding goal meter
 - wallet activity log

IMPORTANT: This is a DEMO ONLY (no real money, no real ads).

How to use
----------
1) Open index.html in your browser (double-click).
2) Use the top navigation to switch screens.
3) Click "Watch Ad" (simulates 5s ad) to earn coins.
4) Try a Phrase Challenge and claim daily goals.
5) Visit "Referrals" to generate or apply a code.
6) Track progress in "Funding Progress" and "Wallet".

Customize rewards & limits
--------------------------
Open app.js and edit the constants at the top, e.g.:
  ADS_DAILY_LIMIT, COINS_PER_AD, COINS_DAILY_CHALLENGE,
  COINS_WEEKLY, REFERRER_REWARD, REFEREE_REWARD, FUND_TARGET, etc.
